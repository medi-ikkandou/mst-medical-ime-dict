# mst-medical-ime-dict

医療従事者向けの、日本語入力（IME）のユーザー辞書です。医薬品名・傷病名・副作用名・医療略語を、読みや略語から変換できるようにします。

対応する IME は次の 2 つです。

- Google 日本語入力（Mozc）
- Microsoft IME

Mac をお使いの方は、Google 日本語入力をお使いください。

## 何が変換できるか

辞書は種類ごとに分かれています。

| 辞書 | 打つ読み | 出る候補 |
|---|---|---|
| 医薬品（medicines） | ろきそにん | ロキソニン |
| 一般名変換（generic_names） | ＠あむろじぴん | アムロジピン錠 など、その一般名の製剤 |
| 一般名変換（絞り込み）（generic_names_narrow） | ＠あむろじぴんODじょう | アムロジンＯＤ錠２．５ｍｇ など、剤形やメーカーで絞った製剤 |
| 傷病名（diseases） | とうにょうびょう | 糖尿病 / diabetes mellitus |
| 副作用名（adverse_reactions） | かんしつせいはいえん | 間質性肺炎 |
| 略語（abbreviations） | dm | 糖尿病 / diabetes mellitus |

一般名変換は、読みの先頭に全角の「＠」を付けて打ちます。

## どれを入れるか

次のどれかを選んでください。

- **薬剤師向けセット**（pharmacist）: 医薬品・一般名変換・副作用名・傷病名。約 8 万行
- **医師向けセット**（doctor）: 傷病名・医薬品・一般名変換・副作用名・略語。約 9 万行
- **全部入り**（all）: すべての辞書。約 17 万行
- **種類ごとの辞書**（dicts）: 必要な辞書だけを選んで入れる

**種類ごとの辞書とセットを混ぜて入れないでください。** Microsoft IME はユーザー辞書が 1 つしかなく、どのファイルから入れた語かを区別できません。両方を入れた後で片方を「テキストファイルで削除」すると、両方に共通する語がすべて消えます。

略語辞書は、`dm` のような英字の読みで変換します。略語は日本語入力のまま英字で打ち、F10（半角英数）か F9（全角英数）を押して英字に戻してから変換してください。英字の入力に影響するのが気になる方は、略語辞書を含まないものを選んでください。

## 入手する

[Releases](../../releases) から、版（日付）ごとの zip を取れます。zip の名前は次の形です。

```
mst-medical-ime-dict-<版>-<セット>-<IME>.zip
例: mst-medical-ime-dict-2026.10.08-pharmacist-msime.zip
```

zip の中の辞書ファイルの名前にも版が入っています。Microsoft IME をお使いの方は、更新のときに旧版のファイルが要るので、zip から取り、ファイルを手元に残しておいてください。

このリポジトリの `mozc/`・`msime/` にも最新版の辞書を置いています。こちらのファイル名には版が入っていません。ここから直接取った場合は、取った日付を控えておいてください。更新のときは、その日付以前で最新の版の zip から、削除用のファイルを取ります。

## 取り込みと更新

### Google 日本語入力

取り込み:

1. 辞書ツールを開く
2. 「管理」→「新規辞書にインポート」で、`-mozc` の付いたファイルを選ぶ

更新:

1. 辞書ツールで、前に取り込んだ辞書を選び、「管理」→「選択した辞書を削除」
2. 新しい版を「新規辞書にインポート」

ご自分で登録した単語は別の辞書にあるので、消えません。

### Microsoft IME

取り込み:

1. ユーザー辞書ツールを開く
2. 「ツール」→「テキストファイルからの登録」で、`-msime` の付いたファイルを選ぶ

更新:

1. 「ツール」→「テキストファイルで削除」で、**前に取り込んだ版のファイル**を選ぶ
2. 新しい版を「テキストファイルからの登録」

前に取り込んだ版のファイルが手元に無いときは、Releases からその版の zip を取ってください。

Microsoft IME での動作は保証しません。取り込める件数の上限は公開されておらず、数万行を超える取り込みは確かめていません。

## 略語の扱い

略語辞書は、略語から日本語名・英語名へ変換する向きだけを収録しています。「とうにょうびょう」から `DM` を出す向きは収録していません。

日本内科学会『病歴要約 作成と評価の手引き』は、確定診断名の欄で略語を用いないとしています。日本診療情報管理学会『診療情報の記録指針 2024』も、記述は日本語が推奨されるとしています。この辞書が略語を作る向きを収録しないのは、これらの指針に沿った判断です。

## 収録の範囲

本辞書は医療用医薬品の名称の変換に対応するものであり、収載品目を網羅するものではない。また、内容が最新であることを保証せず、更新の時期についても約束しない。

本辞書は、医薬品の取り違えを防ぐ機能を持ちません。
